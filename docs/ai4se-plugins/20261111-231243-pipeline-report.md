3. **run #11 (`0607fc7`, the acceptance job pinned to `ubuntu-24.04`)** — same failure, 12m23s. The
   annotation named the step again; the checkout of the pinned image did not change the outcome.
4. **Diagnosis** — the step's apt phase spent the whole time retrying
   `Temporary failure resolving 'azure.archive.ubuntu.com'`. The runner image already ships Chrome
   and the libraries Chromium needs, so fetching system packages was pure risk.
5. **run #12 (`a11bffd`)** — `--with-deps` removed, the browser binary cached on the lockfile hash
   (`actions/cache`), and the job kept on `ubuntu-24.04`; `acceptance tests` now takes 2m25s. Green.

Local cross-check before the fix: `CI=true npm run test:e2e` passed 20/20 in 48.7s on the same
commit, which is why the failure was attributed to the runner's apt rather than to the suite.
